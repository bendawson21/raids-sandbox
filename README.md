# Raids — character sandbox (playable demo)

**Watch:** https://bendawson21.github.io/raids-sandbox/ opens the battle sim: five race
factions fight over the centre of a pentagon arena (WASD pan, wheel zoom, Q/E orbit,
[ ] speed, P pause). Desktop browser with WebGL; no install.

**Character sandbox:** https://bendawson21.github.io/raids-sandbox/sandbox/ —
WASD move · mouse aim · LMB attack (hold to draw a bow) · RMB block with a shield ·
Space dodge · 1–7 outfits · side panel: race, equipment, palettes, animation viewer.

Built files only, published from the private source repo with `tools/publish_sandbox.sh`.
The animation data includes motion converted from Mixamo, licensed for use in the game;
it is not for reuse or redistribution as standalone assets.
